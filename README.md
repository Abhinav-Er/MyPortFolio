# Abhinav Kumar — Personal Portfolio Website

A responsive student portfolio built with HTML, CSS, and JavaScript for the IT4048 Version Control with Git and GitHub mini project.

## Files
- `index.html` — page content and sections
- `style.css` — responsive white and navy-blue styling
- `script.js` — mobile menu, active navigation, contact form, and current year
- `assets/` — add your résumé PDF and optional profile photo here

## Run locally
1. Open this folder in Visual Studio Code.
2. Open `index.html` in a browser, or use the **Live Server** extension.
3. Test the navigation, responsive layout, and contact form.

## Before publishing
1. Add your résumé PDF at `assets/resume.pdf`.
2. Replace `YOUR_EMAIL@example.com` in `index.html` and `script.js` with your email.
3. Replace the placeholder GitHub and LinkedIn URLs with your actual profile URLs.
4. Update each project GitHub link to the correct public repository URL.
5. Add your own profile photo if you want one. The current design uses an initials placeholder.

## GitHub Pages
Create a public repository named `Abhinav_PortfolioWebsite`, upload these files to the repository root, then go to **Settings → Pages** and select deployment from the `main` branch and `/ (root)`. Wait for GitHub Pages to publish the site, then test the live URL.

## Important
GitHub Pages hosts static websites. The contact form currently uses a `mailto:` link and opens the visitor's email app; it does not send or store messages on a server. A PHP backend will not run on GitHub Pages.
